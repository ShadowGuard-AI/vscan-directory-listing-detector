# vscan-directory-listing-detector
Checks if directory listing is enabled on web servers, potentially exposing sensitive files and information. - Focused on Lightweight web application vulnerability scanning focused on identifying common misconfigurations and publicly known vulnerabilities

## Install
`git clone https://github.com/ShadowGuardAI/vscan-directory-listing-detector`

## Usage
`./vscan-directory-listing-detector [params]`

## Parameters
- `-h`: Show help message and exit
- `-t`: Timeout for the HTTP request in seconds. Default is 5.
- `-v`: Enable verbose logging for debugging.
- `-o`: No description provided
